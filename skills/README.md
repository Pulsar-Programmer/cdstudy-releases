# Cd Study skills

The skills that ship with [Cd Study](https://celedus.app). Each folder holds one `SKILL.md`.

| Skill | What it does | By |
| --- | --- | --- |
| [curriculum](./curriculum/SKILL.md) | See every topic you need to study for your course or exam. | Cd Study |
| [expand](./expand/SKILL.md) | Open a separate study thread for each curriculum item you choose. | Cd Study |
| [quiz-me](./quiz-me/SKILL.md) | Test yourself one question at a time and learn from your mistakes. | Cd Study |
| [flashcards](./flashcards/SKILL.md) | Turn a topic or notes into a flashcard set in your Library. | Cd Study |
| [mathiaschu/watch](./watch/SKILL.md) | Watch a video from YouTube or most sites, or a local file, and answer questions about it. | [mathiaschu](https://github.com/mathiaschu/claude-video) |

## Use one

- **Cd Study:** they are already there. Pick one from **Skills** above the chat, or type `$`.
  To add one again, choose **Add skill** and paste its folder link, such as
  `github.com/Pulsar-Programmer/cdstudy-releases/tree/main/skills/quiz-me`.
- **Claude Code, Codex, and other agents:** `npx skills add Pulsar-Programmer/cdstudy-releases`.

Skills by other authors keep their credit and link back to their repository.

These mirror the defaults in the Cd Study app. Change a skill there first, then here.
